# 결과 업데이트: 역할별 집필·검증

현재 사용자 요청이 초기 단일 에이전트 규칙을 대체한다. 각 역할은 첨부 원문과 이 프로젝트용 역할 문서를 읽고 적용한다.

| 역할 | 원문 | 책임 | 산출물 |
|---|---|---|---|
| master | master.md | 작업 배분, 독립 수치 확인, 해석 수용, 연구 상태 | 계약·감사·상태 |
| experiment | experiment.md | 원본 재검증, 통계 재현, 실측 그림 | 검증 JSON·보고서·PNG/PDF |
| writing | writing.md | 파일에서 직접 수치 확인, 결과에 맞춘 논문 수정 | paper-v1.md·claim-map-v1.md |

Open now: 완료 실험 검증과 집필 준비를 병렬 수행. 최종 집필 통합은 검증 산출물에 의존한다. Open later: master가 양쪽 인계와 수치를 확인해 수정본을 채택하고 Obsidian에 반영. Not currently needed: 새 실험, 새 연구 방향 실행, 외부 제출.

이전 자동 생성 v0, template, claim-map, workflow, closeout과 inputs는 재현을 위해 보존한다. 현재 문서는 v1 파일들이며 README와 state.json이 최신 산출물을 가리킨다. 미측정 예상값은 사용하지 않는다. 실측 효과와 불확실성을 함께 보고하고, 설명용 예시는 실측 그림과 구분한다.

원문에 포함된 Depth-AR 실험, 3시간·4쪽 제한, 모델/하드웨어 예시, 자동 push, 숨겨진 예상 수치, NLL 우선 실행 규칙은 현재 프로젝트의 조건이 아니다. 각 역할의 실제 적용 범위는 roles/와 contract-v1.json에 명시했다.
