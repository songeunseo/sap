DLM PRUNING / ALGORITHM OVERVIEW

DLM pruning의 전체 알고리즘 프레임워크

하나의 정적 가중치 마스크를 고르되, 마스크를 적용한 모델이 부분 공개 문맥에서 원래 모델의 응답을 얼마나 유지하는지 사용해 층별 제거량을 배분한다.

이 그림에서 기억할 세 가지

A: 한 상태를 보존

각 문맥에서 Sparse 응답이 Dense 응답과 가까운지 본다. A = 평균(eᵢ²).

C: 변화 방향을 보존

문맥이 바뀔 때 두 모델의 응답 변화가 같은지 본다. C = 평균[(eⱼ−eᵢ)²].

최종 산출물

선택한 가중치만 0으로 만든 하나의 정적 Sparse 모델. 추론 때마다 새 마스크를 만들지 않는다.
