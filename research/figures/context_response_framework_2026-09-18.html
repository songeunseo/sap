DLM PRUNING · PROPOSED FRAMEWORK · 2026-09-18

문맥 반응을 보존하며 pruning 예산을 배분하기

현재 논의 중인 후속 설계안 · 아직 미구현. 총 sparsity 50%, 원래 weight 값과 Wanda 순서는 고정하고 배분만 바꾼다.

A와 C가 비교하는 것

A — 예측 보존: 문맥 변화 전과 후 각각에서 sparse와 dense의 예측 차이를 줄인다.

C — 반응 보존: 문맥이 바뀌었을 때 sparse의 예측 갱신이 dense의 예측 갱신과 비슷하도록 한다.

C = ‖(S₁ − S₀) − (D₁ − D₀)‖²

S₀/S₁과 D₀/D₁은 같은 masked query의 전후 readout이다. 벡터 설계에서는 centered logits를 사용한다. λ와 평균 방식은 후보 비교 전에 고정한다.

반복해서 바꾸는 것은 배분

Wanda가 정한 각 row 내부의 순서는 그대로 두고, 어디까지 제거할지만 조정한다. 복원하는 값도 원래 weight 값이다.

후보와 현재 mask는 같은 문맥 쌍으로 비교한다. 개선되지 않으면 현재 mask를 유지한다.

교환 크기·후보 수·종료 조건은 아직 확정 전이다. Gradient는 선택 가능한 후보 추천 방식이다.

이 그림은 최근 논의한 후속 알고리즘 설계안이다. 기존 mini100 실험은 48/52% probe → layer 순위 → 45–55% 배분을 사용했다.
문맥 쌍의 기본 예시는 token reveal이며, 같은 mask 개수의 문맥 쌍은 별도 대조다. 도식화를 위해 새 실험은 실행하지 않았다.
스타일: 기본 밝은 배경. 온라인에서는 Geist / Noto 계열, 오프라인에서는 설치된 CJK 글꼴로 대체된다.
